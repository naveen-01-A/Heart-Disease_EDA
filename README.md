❤️ Heart Disease Prediction
About Project

This project is used to predict heart disease using Machine Learning.

It checks patient health data like age, blood pressure, cholesterol and heart rate to predict heart disease.

Technologies Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Scikit-learn
Jupyter Notebook
Dataset

The dataset contains patient health information.

Some features are:

Age
Sex
Chest Pain
Blood Pressure
Cholesterol
Heart Rate
